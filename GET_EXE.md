# Как получить готовый Mandarin.exe

Это **бесплатная полная версия**: все функции открыты, без пробного периода, ключей и ограничений.

Собрать Windows-программу можно только на Windows. Есть два пути — выберите любой.

---

## Путь 1. Без своего компьютера — через GitHub (рекомендую)

Ничего устанавливать не нужно, сборку сделает бесплатная облачная машина. ~15 минут.

1. Заведите бесплатный аккаунт на **github.com**.
2. Нажмите **New repository** (можно Private), назовите, например, `mandarin`, создайте.
3. На странице репозитория → **Add file → Upload files** → перетащите в окно браузера **всё содержимое папки `mandarin`** (файлы и папки `tests`, `server`, `site`, `.github` и т. д.) → **Commit changes**.
4. Вкладка **Actions** → слева **Build Windows** → справа **Run workflow** → зелёная кнопка **Run workflow**.
5. Дождитесь зелёной галочки. Откройте завершившийся запуск → внизу раздел **Artifacts**:
   - **Mandarin-Setup** — установщик. Скачается как `Mandarin-Setup.zip`, внутри `Mandarin-Setup.exe`.
   - **Mandarin-portable** — версия без установки. Распакуйте и запускайте `Mandarin.exe`.
6. Распакуйте и запустите. Готово.

## Путь 2. На своём компьютере с Windows

1. Поставьте **Python 3.12** с python.org (галочка **Add python.exe to PATH**).
2. Распакуйте проект, двойной клик по **`build.bat`**. Через несколько минут появится `dist\Mandarin\Mandarin.exe` — его уже можно запускать.
3. Нужен установщик `Setup.exe`? Поставьте бесплатный **Inno Setup** (`winget install JRSoftware.InnoSetup`) и запустите `build.bat` снова — появится `dist-installer\Mandarin-Setup.exe`.

---

## Запуск

- **Установщик** `Mandarin-Setup.exe` — двойной клик, пара кнопок «Далее», в конце можно сразу запустить. Прав администратора не требует, ставится в профиль пользователя. Удаляется как обычная программа через «Параметры → Приложения».
- **Портативная версия** — распакуйте папку куда угодно и запускайте `Mandarin.exe`. Удалить полностью — `uninstall.bat` в той же папке.

После первого запуска значок мандарина появляется в трее у часов. Перетащите файл в Проводнике и нажмите **Shift** — появится колесо форматов.

## Предупреждение Windows при первом запуске

Программа не подписана платным сертификатом, поэтому SmartScreen может показать синее окно **«Windows защитила ваш компьютер»**. Это нормально для любых бесплатных неподписанных программ. Нажмите **«Подробнее» → «Выполнить в любом случае»**. Чтобы убрать это предупреждение совсем, нужен сертификат подписи кода (покупается отдельно; из России сейчас это сложно).

## Проверка, что это именно бесплатная версия

В окне программы нет кнопки «Купить Pro», в меню значка в трее нет пункта про лицензию, на плитках нет замков. Если хотите позже сделать платную версию с ключами — она включается одной строкой (`MANDARIN_FREE=0`), см. SALES.md.
